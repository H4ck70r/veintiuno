# Court card artwork

The jack, queen and king images (`*.svg` in this directory) are the English pattern
playing cards by **Dmitry Fomin**, published on Wikimedia Commons and dedicated to the
public domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

Source: <https://commons.wikimedia.org/wiki/File:English_pattern_playing_cards_deck.svg>

Only the RDF metadata and Inkscape view settings were removed; the artwork is unchanged.
